Astrotop combines a Rust backend for low-overhead metrics collection with a SwiftUI/TypeScript frontend to deliver real-time system performance dashboards — including GPU metrics and predictive analytics.

---

## Installation

```bash
git clone https://github.com/NoamFav/Astrotop
cd Astrotop && make install
```

---

## Features

- Predictive performance analytics
- Comprehensive GPU metrics
- Interactive visualization charts
- Multi-source data aggregation
